# Widescreen Kit

Installs Widescreen's drivers and production software on a company laptop.

Current kit version: **2026.10.11.2251** - the download below is always the newest.

## Install (about 2 minutes)

1. **[Download the setup](https://github.com/sufyanyoussef10-beep/widescreen-kit-setup/releases/latest/download/Widescreen-Kit-Setup.zip)**
2. Right-click the downloaded **Widescreen-Kit-Setup.zip** > **Extract All** > **Extract**.
3. In the folder that opens, double-click **Install Widescreen Kit.bat** and click **Yes**.
   If Windows says "Windows protected your PC": click **More info** > **Run anyway**.
4. Type the **company password** (ask your admin) and press Enter.
5. **Widescreen Kit** opens. Tick the apps you need and press **Install**.

The kit stays on the desktop and in the Start menu. Every time it opens it gets the newest apps and updates by itself.
Nothing is installed until you press Install.

If the kit ever says the company key was refused, download the setup again and run it.

The installers are not on this page: they stay private, and only the company password unlocks them.
